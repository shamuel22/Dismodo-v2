# Muse task 001 — `@dismodo/sdk`: typed TypeScript client for the DISMODO API

You are working in a git worktree of the DISMODO repository (an adaptive learning engine). Read these first:
`README.md`, `packages/contracts/src/*.ts`, `apps/api/src/routes/*.ts`, `apps/api/src/server.ts`,
`apps/api/src/routes/sessions.test.ts` (shows real request/response shapes).

## Goal

Create `packages/sdk` (package name `@dismodo/sdk`): a small, dependency-free TypeScript client (uses global
`fetch`) that external products and the MCP server will use. It must cover **only routes that exist** in
`apps/api/src/routes/`. Do not invent endpoints.

## Allowed files

Only create/modify files under `packages/sdk/`, plus adding `@dismodo/sdk` to nothing else. Do NOT modify
`packages/contracts`, `packages/engine`, `packages/activities`, `packages/adaptation` or `apps/api`.

## Requirements

1. `createClient({ baseUrl, apiKey?, fetch? })` returning methods grouped by area:
   - `packages`: `validate(pkg)`, `import(pkg)`, `list()`, `get(experienceId, version)`, `publish(experienceId, version, { reviewer, contentHash? })`
     (publish fetches the attestation statement from `GET /v1/packages/attestation` and sends it verbatim).
   - `experiences.search(q?)` → `GET /v1/experiences`.
   - `sessions`: `start({ experience, learnerRef, declared?, policy? })`, `get(id)`, `submit(id, action, { clientEventId? })`,
     `evidence(id)`, `events(id)`.
   - `learners`: `history(learnerRef)`, `resetHistory(learnerRef, { skillKey? })`.
   - `metrics.decisions()`.
   - `catalog`: `experienceSchema()`, `components()` (public, no key needed).
2. A separate `createRuntimeClient({ baseUrl, sessionToken, fetch? })` for the learner link
   (`Authorization: Session <token>`): `view()`, `submit(action, { clientEventId? })`, plus a helper
   `tokenFromSessionUrl(url)` that reads the token after `#`.
3. Types: import request/response shapes from `@dismodo/contracts` where they exist (`LearnerAction`,
   `DeclaredContext`, `ExperiencePackage`, `ValidationIssue`, ...). Where the API returns shapes not in contracts,
   declare interfaces in `packages/sdk/src/types.ts` that match the real responses exactly.
4. Errors: non-2xx responses throw `DismodoApiError` with `status`, `code`, `message`, `details` from the API's
   `{ error: { code, message, details? } }` shape. 429 must be distinguishable (`code === 'rate_limited'`).
5. Optional automatic `clientEventId` generation for `submit` when not given (use `crypto.randomUUID()` with
   dashes removed is fine; must match `^[A-Za-z0-9_-]{8,64}$`).
6. `package.json` like other packages (`"type": "module"`, `main`/`types`/`exports` → `./src/index.ts`,
   scripts `typecheck` and `test`), `tsconfig.json` extending `../../tsconfig.base.json` with `"lib": ["ES2023", "DOM"]`.
7. Tests (`vitest`) in `packages/sdk/src/*.test.ts` using a mocked `fetch` (no network, no database): verify
   URLs, methods, headers, bodies, error mapping, token parsing and runtime client behaviour.
8. A short `packages/sdk/README.md` with real usage examples (no real keys; use `dsm_...` placeholders).

## Code style

Match the repo: strict TypeScript, ESM, single quotes, 2 spaces, concise doc comments explaining "why".
